# Global Learning Adventure

Site vitrine de l’agence Global Learning Adventure à Ouagadougou.

Les fichiers du site sont dans `site/`. Chaque push sur `main` vérifie le JavaScript, prépare les fichiers statiques et déploie sur GitHub Pages via GitHub Actions.

Dans les paramètres GitHub Pages du dépôt, choisir la source **GitHub Actions**.

La carte utilise la station April Oil à la ZAD comme repère. Les liens des réseaux sociaux restent à renseigner avec les adresses officielles.
